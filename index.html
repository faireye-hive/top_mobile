Como jogar

Toque no chão para andar, no monstro para atacar e no NPC para conversar. Arraste itens e janelas com um dedo.

Use o direcional para andar e arraste “Câmera” para olhar em volta. Dois dedos no cenário giram a câmera e ajustam o zoom.

No teclado: WASD anda, I abre a bolsa, C o personagem e K as habilidades. Os botões 1–4 usam os atalhos do personagem.

Salve antes de fechar. Para jogar sem as barras do navegador, use tela cheia ou adicione o jogo à Tela de Início. A primeira visita precisa de conexão para baixar os recursos.
